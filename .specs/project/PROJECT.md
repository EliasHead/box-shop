# PROJECT: Box-Shop

## Vision
Plataforma SaaS Multi-Tenant inovadora e de alto padrão para e-commerce (Lojas Virtuais). O objetivo é permitir que lojistas criem suas próprias lojas com facilidade, utilizando roteamento avançado baseado em subdomínios, num ambiente escalável, seguro e com UI moderna (Shadcn + Next.js 14+).

## Goals
- Multi-tenancy nativo com separação rigorosa de dados por `tenantId`.
- Autenticação forte e autorização baseada em cargos (Role-Based Access Control).
- Interface administrativa premium para lojistas.
- Roteamento de frente de loja (storefront) dinâmico baseado no hostname.
- Testes automatizados (Unitários e Integração) garantindo estabilidade a longo prazo.
